# Aniori — Стриминг аниме

Веб-приложение для просмотра аниме с каталогом, поиском, фильтрами, профилем и историей просмотров.

## Стек

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Supabase** (аутентификация)

## Запуск

```bash
npm install
npm run dev
```

Открой [http://localhost:3000](http://localhost:3000).

## Настройка Supabase

1. Создай проект на [supabase.com](https://supabase.com)
2. Скопируй `.env.local.example` в `.env.local`
3. Заполни `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY`

## Структура

```
app/           - страницы (каталог, просмотр, профиль, авторизация)
components/    - переиспользуемые компоненты
lib/           - данные аниме, утилиты, Supabase-клиент
```

## Возможности

- Каталог с фильтрами по жанру, статусу и сортировкой
- Поиск по названию и жанру
- Страница просмотра с автоматическим сохранением истории
- Профиль с кастомизируемыми блоками
- История просмотров (localStorage)
- Авторизация через Supabase (регистрация / вход / выход)
